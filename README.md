# Petone Shopify Theme

Custom Online Store 2.0 theme for Petone — brand colors `#060709`, `#53BD8E`, `#FFFFFF`.

## Connect to Shopify
Online Store → Themes → Add theme → **Connect from GitHub** → choose this repo and branch.

## Homepage sections
Announcement bar · Header · Hero banner · Trust badges · Bundle grid · Product tabs carousel · Brand story · FAQ · Footer

## Product badges
Add product tags like `badge:New`, `badge:Top 1`, `badge:Just Launched`.
